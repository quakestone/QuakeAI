SKILL 管理
什么是 SKILL
独立于模型的表达线：只登记「标题 + 提示词正文」。选中并发送时，它的提示词作为 system 消息注入本轮对话，模型按它的指令作答——与选哪个模型无关。
默认对话 skill
设为默认的会在每次发送自动带上（最多 3 个），首页「默认 skill」开关可一键暂停。系统级 skill（深度思考 / 智能搜索）由系统硬编码，不在此列表罗列，只在首页以图标开关出现。
二级分类

本设备 Key （浏览器级 · 只在本机生效）

多人共用一个网关时，A 不想用 B 登记的 Key：在这里按 provider 录入本设备自己的 Key。它只随本浏览器请求生效（请求头 x-device-keys），不写入共享账本；仅当对应渠道没登记共享 Key 时才会用这里的。留空保存 = 清除，清除后回退共享账本 Key。

TTS 兜底（网关播不了时怎么办）
默认开：网关没有 TTS 模型、Key 失效或超时时，自动退回本机语音合成，保证"点播放有声音"。关掉则只走网关，失败就报错。

工作流参数 浏览器侧 WASM · 本地执行、服务端零存储

Rust 编译的 WASM 内核跑在主线程：每次回答结束后自动执行 ① token 流用量记账 ② LLM 总结历史标题 ③ 会话记忆更新（WASM 状态机按 token 阈值自适应触发）④ 附件显示规格。全部在本地执行、服务端零存储；模型调用走网关自身（计入账本）。

接入方式 OpenAI 兼容端点

响应头 x-gateway-channel / x-gateway-attempts 可观测命中渠道与降权链（如 ch-a=HTTP429;ch-b=ok）。

上游转发 脱钩 Cloudflare 后必填

浏览器直连智谱等上游会被 CORS 拦截。在此填写你自己的「上游转发 URL」（能转发请求的服务，例如你部署的 Worker / 服务器）。网关把真实上游地址放在 x-gw-target 头、原样转交 method / headers / body，由转发服务去真正请求上游。留空 = 直连（将被 CORS 拦截，对话不可用）。

管理面鉴权

纯客户端应用无服务端密钥：这里填的「管理口令」只存本浏览器 localStorage（键 gw_admin_token），用于给 /admin/api/* 请求带 x-admin-token 头、做一层本地软锁。留空 = 不鉴权。
