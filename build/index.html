UPSTREAM & ACCESS

上游与接入

纯静态部署脱钩 Cloudflare 后：转发代理、OpenAI 兼容接入、管理面软锁、本设备 Key 与部署自检——全部只存本机。

⇱ 上游转发代理 F25

浏览器直连智谱等上游会被 CORS 拦截。填写你自己的转发服务地址（Worker / 服务器均可），网关把真实上游地址放在 x-gw-target 头、原样转交 method / headers / body。留空 = 直连（将被 CORS 拦截，对话不可用）。

⌘ 管理面鉴权 F27

纯客户端应用无服务端密钥：口令只存本浏览器 localStorage（键 gw_admin_token），给 /admin/api/* 请求带 x-admin-token 头做一层本地软锁——网关侧强制校验，配了不带头即 401。留空 = 不鉴权。

⌸ 接入方式 F26 · OpenAI 兼容端点

任何 OpenAI 兼容客户端都能直接接本网关（Base URL 即本站地址）：

curl <gateway>/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"glm-4-flash","stream":true,"messages":[{"role":"user","content":"你好"}]}'

# 音频 multipart 上传（同端点，任意二进制）
curl <gateway>/v1/audio/transcriptions -F 'file=@sample.wav' -F 'model=glm-asr-2512'

响应头 x-gateway-channel / x-gateway-attempts 可观测命中渠道与降权链（如 ch-a=HTTP429;ch-b=ok）。自定义头约定：x-gw-target（代理转发）、x-gw-features（系统级能力）、x-device-keys（本设备 Key）、x-admin-token（管理面软锁）。

🔑 本设备 Key F19 · 浏览器级

多人共用一个网关时，不想用别人登记的共享 Key：在这里按 provider 录入本设备自己的 Key。只随本浏览器请求生效（x-device-keys 头），不写入共享账本；仅当对应渠道没登记共享 Key 时才会用这里的。留空保存 = 清除。
